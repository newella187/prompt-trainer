Grounding Prompt Training Course

Learn how to ground GPT responses, test your understanding, and generate grounded prompts.

1) Course: How to Ground a GPT

  1. Define scope: state exactly what the model must answer and what is out of scope.
  2. Provide trusted sources: include policies, notes, reports, or approved facts.
  3. Set evidence rules: require the model to use only supplied material and cite it.
  4. Specify output format: choose bullet points, summary, table, or action list.
  5. Add uncertainty handling: instruct the model to say when evidence is missing.
  6. Review and refine: check for assumptions, then tighten instructions.
